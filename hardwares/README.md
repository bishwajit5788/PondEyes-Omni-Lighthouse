# PondEyes Hardware Photos

This directory contains reference photographs of the physical hardware received for the PondEyes Omni-Lighthouse project.

## Photo Index

| File | Description |
|---|---|
| `radar_modules_6x_hlk_ld2450.jpeg` | Six HLK-LD2450 radar modules |
| `battery_cells_18650.jpeg` | 18650 Li-ion battery cells |
| `electrolytic_capacitors.jpeg` | Electrolytic capacitors |
| `yellow_capacitors.jpeg` | Yellow axial/lead capacitors |
| `control_boards_teensy_xiao_antenna.jpeg` | Two Teensy 4.1 boards, one XIAO ESP32-S3, antenna and RF cable/bulkhead |
| `complete_hardware_inventory.jpeg` | Overall hardware inventory photograph |

These photos document the hardware physically received for the prototype and are intended for build documentation and future assembly reference.
